# Speed Reading Site

This repository hosts the public website and privacy policy for the **Speed Reading Trainer** Android application.

## Pages

- Website: https://arkanmgerges.github.io/speed-reading-site/
- Privacy Policy: https://arkanmgerges.github.io/speed-reading-site/privacy-policy.html

## Purpose

The repository contains only public-facing static pages used for the app's Google Play listing and compliance information.

The Android application source code is maintained separately and is not published in this repository.
